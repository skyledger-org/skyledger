# SkyLedger

**Satellites see the leaks. Companies report the numbers. SkyLedger is an AI agent team that checks one against the other.**

SkyLedger reconciles methane plumes observed from space (Carbon Mapper / Tanager, NASA EMIT) with facility self-reports to the US EPA (GHGRP) and corporate ownership (SEC EDGAR). These sources share no keys, units or clocks. It queries them in place through Zetaris, resolves owners with the Meterless World Model, and verifies each plume's source with NVIDIA Nemotron vision. A Skeptic agent must rule out five rival explanations before any discrepancy is reported.
