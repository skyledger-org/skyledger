01 · The problem

Three sources that were never designed to meet.

No shared keys. No shared units. No shared clocks. Joining them by hand is how a plume gets blamed on the wrong plant.

  1. Sky

    A plume is a point and a rate

    Carbon Mapper sees methane from aircraft and satellites (Tanager, EMIT, AVIRIS-NG, GAO): kilograms per hour, on one morning. For example kg/h on .

  2. Ground

    A report is a facility and a year

    Facilities self-report to the US EPA Greenhouse Gas Reporting Program: tonnes of CO₂e for a whole year, sometimes aggregated across an entire basin. reported t CH₄ for RY.

  3. Ledger

    An owner is a free-text string

    Operators, joint ventures and percentages typed many different ways. The Meterless World Model merges them into parent companies. Parent here: .

    03 · The team

    A pipeline that argues with itself.

    Each agent hands its work forward. The Skeptic can block the Reporter, or send a case back to GeoLinker, PlumeReader or the Reconciler, in bounded loops.

          07 · Built on

          Query in place. Reason in the open.

          • Zetaris

            Federated SQL. GeoLinker joins plumes to facilities and reported CH₄ across sources, with the data queried where it lives instead of copied into a new warehouse.

          • Meterless

            Nightshift is the primary AI provider. The World Model engine resolves owner strings to parent companies, and sign-off uses Scout-shaped execution contracts.

          • NVIDIA Nemotron

            Reads the plume image blind and writes the draft dossier in guarded language. A guard rejects any number in the text that the code did not compute.

          • Cursor

            Where the product was developed, with its project rules kept in the repository.

          An honest note: Nightshift 1.2.7 refuses image inputs, so the plume-image check falls back to NVIDIA's API directly. Text generation runs through Nightshift. Product names are trademarks of their owners and appear here only to describe what SkyLedger runs on.
